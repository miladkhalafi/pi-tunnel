Register {{ pi.name }}

Run the install script on your Raspberry Pi to set up the SSH tunnel.

  1. On your Raspberry Pi, run this command: 
    curl -sSL {{ script_url }} | bash
  2. The script will:
    • Generate an SSH key if needed
    • Send the public key to this server
    • Add the server's public key to the Pi's authorized_keys
    • Configure the reverse SSH tunnel (autossh systemd service)

When WEB_URL or SERVER_URL is set on the server, the script runs fully headless with no prompts.

Uninstall

To remove the tunnel from the Pi, run:

curl -sSL {{ base_url }}/register/{{ pi.token }}/uninstall-script | bash
