Register {{ pi.name }}

On your Raspberry Pi (headless), run:

curl -sSL {{ script_url }} | bash

The script will:

  • Generate an SSH key if needed
  • Send the public key to this server
  • Add the server's public key to the Pi's authorized_keys
  • Configure the reverse SSH tunnel (autossh systemd service)

When SERVER_URL is set on the server, the script runs fully headless with no prompts.
